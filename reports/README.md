# Reports

Bu klasör yalnızca kalıcı, insan tarafından okunacak raporları barındırır.

- Toplu özet raporları: `reports/comparisons/`
- Kitap bazlı karşılaştırma raporları: `reports/comparisons/books/`
- Geçici çalışma notları repo içine yazılmaz
- Makine verileri `generated/json/` ve `generated/json/books/` altında tutulur
