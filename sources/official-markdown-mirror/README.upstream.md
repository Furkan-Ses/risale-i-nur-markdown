# Official Markdown Mirror

Bu klasör, repo içinde karşılaştırma ve yeniden üretim amacıyla korunan **resmî metin hattı aynasını** içerir.

## Rolü

- kaynak dosya yapısını mümkün olduğunca değişmeden saklamak
- `books/` katmanının provenansını korumak
- karşılaştırma scriptleri için sabit bir referans sağlamak

## Notlar

- birincil okuma katmanı `books/` klasörüdür
- AI odaklı kullanım katmanı `ai/` klasörüdür
- bu ayna üzerinde içerik düzenlemek yerine doğrulanmış değişiklikler `books/` katmanında yönetilmelidir

## Metin hattı

- metin hattı: Hizmet Vakfı yayımı / Diyanet asıl nüsha zinciri
- kullanım tipi: araştırma, karşılaştırma ve yeniden üretim
