# Risale-i Nur - Muhakemat by Heading

Bu klasör, **Muhakemat** metninin repo içindeki kanonik referans kopyasını içerir.

## İçerik

- `Muhakemat.md` - tüm bölüm dosyalarının tek dosyada birleşik sürümü
- `by_heading/` - bölüm dosyaları

## Provenans

- Başlangıç kanonik kopya, `upstream/alitekdemir/obsidian-markdown/14 Muhakemat` kaynağından alınmıştır.
- Upstream set, resmi Hizmet Vakfı public kaynağı ile karşılaştırılmıştır.
- Genel sıra benzerliği: **0.9982**
- Genel içerik örtüşmesi: **0.9981**
- Karşılaştırma durumu: **very-high**
- Ortak bölüm sayısı: **5**
- Upstream-only bölüm: **0**
- Official-only bölüm: **1**

## Düzenleme kuralları

- Dosya adlarını ve `by_heading/` yapısını değiştirmeyin.
- Gerekçesiz toplu biçim değişikliği yapmayın.
- Metin düzeltmesi yapılırsa dayanak belirtin: resmi public metin, baskı karşılaştırması veya güvenilir referans.
- Türkçe ve Arapça satırları UTF-8 olarak koruyun.
