# Risale-i Nur - Lemalar by Heading

Bu klasör, **Lemalar** metninin repo içindeki kanonik referans kopyasını içerir.

## İçerik

- `Lemalar.md` - tüm bölüm dosyalarının tek dosyada birleşik sürümü
- `by_heading/` - bölüm dosyaları

## Provenans

- Başlangıç kanonik kopya, `upstream/alitekdemir/obsidian-markdown/03 Lem'alar` kaynağından alınmıştır.
- Upstream set, resmi Hizmet Vakfı public kaynağı ile karşılaştırılmıştır.
- Genel sıra benzerliği: **0.9981**
- Genel içerik örtüşmesi: **0.9972**
- Karşılaştırma durumu: **almost-identical**
- Ortak bölüm sayısı: **36**
- Upstream-only bölüm: **0**
- Official-only bölüm: **0**

## Düzenleme kuralları

- Dosya adlarını ve `by_heading/` yapısını değiştirmeyin.
- Gerekçesiz toplu biçim değişikliği yapmayın.
- Metin düzeltmesi yapılırsa dayanak belirtin: resmi public metin, baskı karşılaştırması veya güvenilir referans.
- Türkçe ve Arapça satırları UTF-8 olarak koruyun.
