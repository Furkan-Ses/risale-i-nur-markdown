# Risale-i Nur - Tarihce-i Hayat by Heading

Bu klasör, **Tarihce-i Hayat** metninin repo içindeki kanonik referans kopyasını içerir.

## İçerik

- `Tarihce-i Hayat.md` - tüm bölüm dosyalarının tek dosyada birleşik sürümü
- `by_heading/` - bölüm dosyaları

## Provenans

- Başlangıç kanonik kopya, `upstream/alitekdemir/obsidian-markdown/05 Tarihçe-i Hayat` kaynağından alınmıştır.
- Upstream set, resmi Hizmet Vakfı public kaynağı ile karşılaştırılmıştır.
- Genel sıra benzerliği: **0.9977**
- Genel içerik örtüşmesi: **0.9971**
- Karşılaştırma durumu: **very-high**
- Ortak bölüm sayısı: **10**
- Upstream-only bölüm: **2**
- Official-only bölüm: **4**

## Düzenleme kuralları

- Dosya adlarını ve `by_heading/` yapısını değiştirmeyin.
- Gerekçesiz toplu biçim değişikliği yapmayın.
- Metin düzeltmesi yapılırsa dayanak belirtin: resmi public metin, baskı karşılaştırması veya güvenilir referans.
- Türkçe ve Arapça satırları UTF-8 olarak koruyun.
